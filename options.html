API 设置

“YouTube字幕翻译器”的 AI 字幕翻译需要你自己的 API 密钥。YouTube 自带翻译无需填写。

支持兼容 OpenAI 的 HTTPS 服务。填写基础地址，例如 https://api.openai.com/v1，不要填写完整接口路径。服务需要提供 /chat/completions。

密钥只保存在当前浏览器的扩展本地存储中，不跨设备同步，也不传给 YouTube 页面。启动 AI 模式后，字幕文本会发送到此地址；服务可能计费。卸载扩展或点击“清除密钥”可以删除本地密钥。

兼容范围和常见问题

电脑端新版 Edge / Chrome 使用同一个 Manifest V3 安装包。要求 Chromium 116 或以上的接口能力。百度浏览器仅在支持该扩展机制及相关 API 时才可能运行，旧内核不兼容；本版没有百度实机验证。
字幕依赖 YouTube 页面和播放器接口，网站更新可能需要适配。仅支持具有人工字幕或自动生成字幕的视频；AI 模式的延迟取决于 API 服务。常规网页全屏支持；系统画中画窗口不能显示扩展叠加字幕。
