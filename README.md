# YouTube字幕翻译器

面向电脑端 Microsoft Edge 和 Google Chrome 的浏览器扩展，将 YouTube 多语言字幕翻译为简体中文。

## 功能

- 支持英语、日语、韩语、法语、俄语、西班牙语等字幕语言。
- 自动选择原始字幕语言，无需手动指定。
- 提供 YouTube 自带翻译和 AI 字幕翻译两种模式。
- AI 模式支持中外文双语显示。
- AI 模式优先保留英文人名原拼写，避免中文音译。
- 支持调整字号、字幕位置和 AI 字幕时间轴偏移。

## 安装步骤

1. 点击本仓库右上方的 Code → Download ZIP。
2. 将下载的 ZIP 解压到固定位置。
3. 打开浏览器扩展管理页面：
   - Edge：edge://extensions/
   - Chrome：chrome://extensions/
4. 开启开发者模式。
5. 点击“加载已解压的扩展程序”或“加载解压缩的扩展”。
6. 直接上传下载好解压后的文件夹。
7. 打开或刷新 YouTube 视频页面。

安装完成后请保留该文件夹，浏览器需要从中读取扩展文件。

## 使用方法

### YouTube 自带翻译

无需 API 密钥。

打开具有字幕的 YouTube 视频，点击浏览器扩展菜单中的
“YouTube字幕翻译器”，开启字幕翻译并选择 YouTube 自带翻译模式。

### AI 字幕翻译

需要用户自己的 API 密钥，使用可能产生费用。

1. 点击扩展中的“API 设置”。
2. 填写 API 基础地址、密钥和翻译模型。
3. 保存并授权 API 站点，测试连接。
4. 返回视频页面，选择 AI 翻译模式。

支持提供 /chat/completions 接口的 OpenAI 兼容 HTTPS 服务。
模型名称、服务权限和网络可用性由服务提供方决定。

英文人名保留规则仅用于 AI 模式。原文没有可靠英文拼写时，
优先保留原文姓名，不编造英文名字。模型仍可能识别人名错误。

## 使用限制

- 视频必须具有人工字幕或 YouTube 自动生成字幕。
- 不支持完全无字幕视频的语音识别。
- AI 翻译速度和准确度取决于所用服务。
- YouTube 自带翻译的人名处理由 YouTube 决定。
- YouTube 页面更新可能导致扩展需要适配。
- 百度浏览器、macOS 和 Linux 尚未实机验证。
- 系统画中画窗口无法显示页面叠加字幕。

## 常见问题

### 开启后仍然显示原文

刷新 YouTube 页面，确认已开启翻译，并点击“重新读取字幕”。
AI 模式还需检查 API 配置；具体错误可在扩展弹窗中查看。

### 提示无法加载图标

请确认 manifest.json 中的图标路径与实际文件位置一致，
且三个图标文件均已下载。

### 找不到 manifest.json

加载扩展时选择包含该文件的文件夹。
文件夹选择窗口可能不会显示文件，这属于正常情况。

## 隐私

API 密钥仅保存在当前浏览器扩展的本地存储中，不跨设备同步。
AI 模式会向用户配置的服务发送字幕、视频标题及有限前文。
本扩展不捕获音频。

请勿把自己的 API 密钥上传到 GitHub。
